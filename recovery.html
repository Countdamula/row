Snapshots

A snapshot is a copy of one app's data as it stood at a moment. Restoring replaces what is on the page now — and takes a snapshot of that first, because an undo needs its own undo.

Unsaved drafts

Text typed into a form but never saved. Open the page it belongs to and it comes back on its own; this is only here so you can see it exists.

Waiting to sync

Send this device's copy up

Each app keeps one row in the cloud, and the last device to write it wins. If a row was emptied or overwritten by something else, this marks everything this device holds as unsent — so the next time you open that app it uploads instead of downloading, and the cloud stops being able to delete it.

Use it when this device has the good copy. Anything a different device wrote and never synced could be lost.

Export

JSON is the format that restores. Markdown is the one that still opens in ten years with no dashboard at all.

Restore from a file

Reads a JSON export and writes those records back. It only adds and overwrites — nothing is deleted, so a file that is missing something cannot take it away from you. Restored records are then pushed to the cloud.

Make a restore point

Before a big change, name a snapshot so you can find it later. Named snapshots are never pruned by age.
