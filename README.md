# Personal Dashboard

A set of small, self-contained HTML apps that share a top bar.

## Deploy your own copy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FRowanThistlebrooke%2FYTdashh1)

One click → Vercel signs you in, copies the repo to your GitHub, and deploys it. ~30 seconds to a live URL.

## How to use

Open any `.html` file directly in your browser — no build step, no install.

| File | What it is |
|---|---|
| [promptarium.html](promptarium.html) | Promptarium — the first folder in the nav. A prompt operating system: one collection page per AI model (ChatGPT, Claude, Gemini, Gemini NotebookLM, Suno AI, n8n, Perplexity) — each with a Substack-style guide you write at the top and a rich notes database at the bottom that accepts pasted screenshots and formatting intact — a searchable library filtered by model/category/status/date/rating/tags/creator/purpose and sorted five ways, star ratings that feed a Favorites & Pinned page, a second user-owned tag axis (purpose tags, with usage counts and a cascading delete), Prompt Chains whose ordered steps each carry a copyable sub-prompt, a fill-in-the-variables console and generatable run-checklist notes — seeded with a real 14-step "Idea → Finished Fiction Manuscript" workflow spanning all six tools — and a Quick Capture inbox on a `q` hotkey so a prompt can be saved before it is organized. Every page opens on a tall, left-aligned hero — a hairline display serif word-mark in tracked capitals over a looping muted background video, with scroll parallax. Its **Fiction** collection is not a copy of The Codex's prompt database: the page mounts The Codex's own cloud row, so a fiction prompt edited in either place is the same record |
| [athenaeum.html](athenaeum.html) | The Athenaeum — the second folder in the nav, directly beneath Promptarium. A learning dashboard built on one structural rule: **Field → Curricula → Modules → Lessons**, where a field is permanent and a curriculum is temporary, so concepts, research, connections and contradictions belong to the field and outlive the curriculum that taught them. Every page is full-bleed, and all three heroes share one photograph (`images_by_admin/athenaeum/hero.jpg`, a Vitruvian Man / Leonardo-manuscript collage) with all their text set in Bodoni Moda — a high-contrast Didone in wide-tracked capitals, matching the brand's banner & title reference. The main page is a light editorial surface — a full-bleed photographic hero, a three-way Current / Next / Back Burner curriculum switcher, Today's Learning computed from your own sessions/reviews/assignments, and a scroll-revealed gallery of the eleven permanent fields, each card carrying status, mastery, active curriculum, curricula completed and current focus. Four Standing Systems stay global and are summarised on the homepage, not expanded, each opening its own hash route: the **Retention Center** (`#/retention` — overdue / due today / weak / recently reviewed / mastered, graded Recalled-or-Forgot on a legible 1·3·7·16·35·75·150-day ladder that doubles on a good recall and resets to one on a bad one, every item linking back to its field), the **Learning Calendar** (`#/calendar` — one month grid, five colour-coded session kinds: class, study, research, reflection, experiment; click any day to schedule), the **Experiment Lab** (`#/experiments` — global, filterable by field, and the same records a field hub shows pre-filtered) and **The Box** (`#/box` — the intellectual parking lot, with Promote-to-next and Back-burner actions that create a real curriculum in the item's field and stamp the entry rather than deleting it). Four more routes roll every field up: `#/inbox`, `#/knowledge`, `#/resources`, and `#/connections`, which draws all eleven fields on one ring with a chord per cross-field link. Companion pages: [athenaeum-subject.html](athenaeum-subject.html) (the Subject Hub — `?id=<fieldId>`) and [athenaeum-curriculum.html](athenaeum-curriculum.html). A parallel build: `learning.html`, `learning-dashboard.html` and `knowledge-hub.html` are untouched, still nav-listed, and share no data and no code with it |
| [athenaeum-subject.html](athenaeum-subject.html) | Subject Hub — one permanent field (`?id=psychology`, `?id=wealth`, …). Inverts the main page into a dark working surface with its own rail. Overview carries the eight field properties (why I study this, what mastery means to me, current understanding, long-term goals, season, current curriculum, curricula completed, total study time); the **Subject Map** is a real parent→child skill tree where each topic records learning status, importance, mastery target, current knowledge, linked curricula and concept count; the **Deep Research Bar** pairs a Learning Inbox (claim / theory / question / example / person / book / idea / controversy / observation) with a permanently visible Research Lens of standing questions you can capture answers against, and any capture can be promoted into a permanent concept in that field. Plus the field's Curricula (Completed / Current / Future) and its filtered slice of the universal Resource Library (Core / Active / Completed / Reference / Suggested / Rejected). The **Knowledge Base** holds the field's permanent concepts — each with a definition, a plain-words explanation, the technical one, examples, evidence, criticism, sources, your own interpretation, a confidence rating and a mastery rung — searchable, filterable by topic, and each concept gets its own page at `#/knowledge/<id>` with two-way related-concept links. **Connections** draws two hand-rolled SVG diagrams: a chord circle for how ideas inside the field relate (Memory → Emotion → Decision Making) and a hub-and-spoke for where this field touches the other ten; a cross-field link is stored once and read from both ends. The **Contradiction Lab** holds two theories side by side — symmetrical by design, so the layout never takes a side — with the evidence for each, the assumptions, the methodological differences, where each may be correct, and your own interpretation with a confidence rating |
| [index.html](index.html) | Main — a Morning Call Sheet ritual (Running Order, Beliefs, Today/Tonight journals), now combined with four tabs: Morning Ritual (the above — its "Move" step links out to the 4th tab), Your System (Top Goals, daily/weekly Actions, Written/Visual/Mental Core Systems), Subconscious Reprogramming (Identity Shifting — Anchors/Future Self Vision/Challenges — plus quick links back into the Ritual tab), Fitness Studio (Templates/Equipment/Current Week with pre-workout coaching + post-workout review/comparison), and Self-Care (a checklist, a Journal with Brain Dump/Gratitude/Day Planner templates, and a Meditations + Breathwork page with an animated breathing pacer; the Ritual tab's Breathe/Sit/Page steps link straight into it) |
| [entertainment.html](entertainment.html) | Media — Spotify/YouTube link gallery |
| [entertainment-dash.html](entertainment-dash.html) | Entertainment — one merged dashboard (replacing the old five-page Entertainment folder and the short-lived Media/mediaverse.html hub, both removed): Home, Discovery Engine, Favorites, Podcasts, Horror/Spicy Stories (each split into a Reading database and a separate YouTube database), Immersive Experience, Entertainment, Playlists, Reading Corner, Anime, Games, and Statistics — styled with the same glass-theme.css/gallery-card.css kit as Fitness Studio/Business Dashboard |
| [knowledge-hub.html](knowledge-hub.html) | Knowledge Hub — its own nav folder directly under Entertainment. A digital note-taking / PKM system: a five-stage capture funnel (Inbox → To Review → Highlighting → Summarizing → Synthesis), Progressive Summarization, Notebooks auto-filed by capture type (each with a Learning Progress bar, an Active Research Hub of two mind maps — a Topic Map and a Questions & Connections Map whose branches auto-generate an article template — and a nine-section Permanent Knowledge Database), a linked Quote Library, a `[[wiki-link]]` Connections graph, one-click Templates (Book/Article/Video/Research/Essay/Jot/Quote), a Today's Focus panel, a Creation Lab, and floating Quick Capture/Media Capture buttons — built on the same glass-theme.css/gallery-card.css kit as Fitness Studio/Entertainment |
| [nutrition.html](nutrition.html) | Nutrition — My Kitchen / Grocery List |
| [learning.html](learning.html) | Learning folder → Topics gallery — Articles/Books/Videos/Posts/Notes, plus each topic's own dedicated page |
| [learning-topic.html](learning-topic.html) | Learning folder → a single Topic's own page (`#<topicId>`) — a Questions database, then that topic's resources, each with a two-column Content/My Notes section generated on demand |
| [learning-dashboard.html](learning-dashboard.html) | Learning Dashboard — a standalone daily-study command center (Home, topic cards, a weekly Gather/Organize/Integrate/Teach workflow, a Daily Study Widget, Research Library, Knowledge Maps, Personal Frameworks, Master Notes with backlinks, Analytics, Settings) — its own crimson/pink theme, genuinely separate from learning.html |
| [dreamboard.html](dreamboard.html) | Dream Board — a drag-and-drop vision board (checklists, calendar, photo/video grid, affirmations, and more) |
| [palaestra.html](palaestra.html) | The Palaestra — its own nav folder directly above Fitness Studio. Opens on a full-screen cinematic hero: a cave-temple clip behind a glowing ring that scales in and then rotates, a headline revealed word by word out of line masks, column hairlines and a left rail that doubles as the route indicator, and a scroll-out that slides the copy as the backdrop scales — then a flowing silk ribbon whose circular badge is the page's primary action (**Start Pull Day** / **Start Today** / **Resume**). Every route has its own affirmation and replays the reveal. A training dashboard built around one device: the **Week Bar**, seven columns where fill height is that day's training volume against the week's best day, hue is the workout's lane (strength / cardio / mobility / rest), an outline-only column is scheduled-but-not-done, and the rule underneath is that day's steps against goal. Hash routes: Today (the workout card, steps, water, macros, bodyweight, plus Consistency streaks and a Weekly Scorecard scoring training/steps/cardio against their goals), Steps (today against goal, 7- and 30-day averages, highest day, current streak, and a year-long heatmap), Body Progress (weight/waist/chest/arms/thighs/hips/body-fat, progress photos, and a Current → Starting → Goal bar), Calendar (a month grid projecting the weekly plan forward, colour-coded, with missed days hatched), Training Volume (sets per muscle this week vs last), Workouts, Exercise Library and History (personal bests by estimated 1RM). Streaks, the scorecard, volume, PRs and step averages are all **derived**, never stored. A parallel build: `fitnessstudio.html` and index.html's own Fitness Studio tab are untouched and still nav-listed — the only contact is an explicit "Import my programs" button that reads their routines and never writes back |
| [palaestra-workout.html](palaestra-workout.html) | The Palaestra → the live workout logger. Wears a shorter band of the same hero — same clip, ring and word reveal — so the first exercise is visible without scrolling, with its ribbon badge set to **Finish Workout** and, on a phone, the clock and controls pinned within reach of a thumb. Its own page rather than a route, because it is the screen used mid-set on a phone and must not repaint when a cloud pull lands. Per exercise: muscle group, equipment, a row per set (weight / reps / RPE / ✓), rest time, notes, photos and videos, a completed toggle, and what you lifted last time as placeholder text. Completing a set **auto-starts the rest timer** at that exercise's own rest value, with 30s · 60s · 90s · 2m · 3m presets on a fixed bar; timer state is stored as absolute timestamps, so a locked phone or a reload resumes rather than resets. `?id=` opens a finished workout read-only. Its side button on every exercise and every workout opens a music dock reading **The Vault's** Music & Playlists shelf, and a track can be pinned to a lift |
| [fitnessstudio.html](fitnessstudio.html) | Fitness Studio — its own new nav folder between Business Dashboard and Entertainment. Genuinely separate from index.html's own embedded Fitness Studio tab. Hero, Today's Workout, a Live Workout Dashboard, Goal Center, Workout Programs, Weekly Schedule, a consistency heatmap, an AI Fitness Coach, Settings (Black/Red/Pink theme), and a music slide-out panel connected live to the Playlists page |
| [writing-dashboard.html](writing-dashboard.html) | Writing Dashboard — its own "Business" nav folder, between Fitness Studio and Entertainment. A full Writing Operating System for multiple fantasy/horror/thriller/romance/sci-fi series at once: a Series Library, a per-series 15-tab Series Dashboard (Worldbuilding Wiki with 56 fixed categories, Character Wiki with a relationship graph, Story Architecture, an interactive trilogy Mind Map, Brain Dump, Tools & Documents, Research, Publishing, Analytics, Timeline, Gallery, Templates), and a per-book 6-tab Writing Workspace (a distraction-free editor with a Quick Lore side panel + an AI Prompt Library side panel, Structure & Beats — real Save the Cat/Hero's Journey/Seven Point/Story Circle/Romance/Three-Act beat sheets plus subplot/foreshadowing/reveal/mystery trackers, Formatting & Export, an honestly-computed Consistency Checker with an optional AI review, and Publishing) — a cinematic black/crimson/charcoal/silver theme built on the glass-theme.css/gallery-card.css kit |
| [aitech.html](aitech.html) | AI & Tech — an AI Models gallery + a linked Prompts database |
| [tasksnotes.html](tasksnotes.html) | Tasks & Notes — Links / Notes / Tasks |
| [mainpillar.html](mainpillar.html) | Main Pillar — gamified daily command center (Whoop biometrics, quest-style habits, tasks, AI journal/briefs, Weekly/Monthly/Year dashboards, Smart Goal Allocation, Favorites archive) |
| [topbar.js](topbar.js) | Shared top bar — auto-injected into pages that `<script src="topbar.js">` |
| [sync.js](sync.js) | Shared Supabase cloud-sync helper |
| [glass-theme.css](glass-theme.css) / [glass-theme.js](glass-theme.js) | Reusable "dark glass" page theme — background glow, glass cards, glare cards, border-beam cards, a cover-photo hero, and drag-reorderable "moveable" sections. Extracted from fitnessstudio.html; drop `<link>`/`<script>` tags into a new page to get the same look/feel (see glass-theme.css's own header comment for how) |
| [gallery-card.css](gallery-card.css) / [gallery-card.js](gallery-card.js) | Reusable gallery card component — cover art, hover-revealed drag handle + edit button, a favorite star toggle, a serif title/creator/subtopic, a clamped description, a 5-star rating row, a length readout, and click-to-open-or-edit. Extracted from ent-stories.html's card (`GalleryCard.build(item, opts)` — see gallery-card.css's own header comment for how) |
