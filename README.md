# Personal Dashboard

A set of small, self-contained HTML apps that share a top bar.

## Deploy your own copy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FRowanThistlebrooke%2FYTdashh1)

One click → Vercel signs you in, copies the repo to your GitHub, and deploys it. ~30 seconds to a live URL.

## How to use

Open any `.html` file directly in your browser — no build step, no install.

| File | What it is |
|---|---|
| [index.html](index.html) | Main — a Morning Call Sheet ritual (Running Order, Beliefs, Today/Tonight journals), now combined with four tabs: Morning Ritual (the above — its "Move" step links out to the 4th tab), Your System (Top Goals, daily/weekly Actions, Written/Visual/Mental Core Systems), Subconscious Reprogramming (Identity Shifting — Anchors/Future Self Vision/Challenges — plus quick links back into the Ritual tab), Fitness Studio (Templates/Equipment/Current Week with pre-workout coaching + post-workout review/comparison), and Self-Care (a checklist, a Journal with Brain Dump/Gratitude/Day Planner templates, and a Meditations + Breathwork page with an animated breathing pacer; the Ritual tab's Breathe/Sit/Page steps link straight into it) |
| [entertainment.html](entertainment.html) | Media — Spotify/YouTube link gallery |
| [entertainment-dash.html](entertainment-dash.html) | Entertainment — one merged dashboard (replacing the old five-page Entertainment folder and the short-lived Media/mediaverse.html hub, both removed): Home, Discovery Engine, Favorites, Podcasts, Horror/Spicy Stories (each split into a Reading database and a separate YouTube database), Immersive Experience, Entertainment, Playlists, Reading Corner, Anime, Games, and Statistics — styled with the same glass-theme.css/gallery-card.css kit as Fitness Studio/Business Dashboard |
| [knowledge-hub.html](knowledge-hub.html) | Knowledge Hub — its own nav folder directly under Entertainment. A digital note-taking / PKM system: a five-stage capture funnel (Inbox → To Review → Highlighting → Summarizing → Synthesis), Progressive Summarization, Notebooks auto-filed by capture type (each with a Learning Progress bar, an Active Research Hub of two mind maps — a Topic Map and a Questions & Connections Map whose branches auto-generate an article template — and a nine-section Permanent Knowledge Database), a linked Quote Library, a `[[wiki-link]]` Connections graph, one-click Templates (Book/Article/Video/Research/Essay/Jot/Quote), a Today's Focus panel, a Creation Lab, and floating Quick Capture/Media Capture buttons — built on the same glass-theme.css/gallery-card.css kit as Fitness Studio/Entertainment |
| [nutrition.html](nutrition.html) | Nutrition — My Kitchen / Grocery List |
| [learning.html](learning.html) | Learning folder → Topics gallery — Articles/Books/Videos/Posts/Notes, plus each topic's own dedicated page |
| [learning-topic.html](learning-topic.html) | Learning folder → a single Topic's own page (`#<topicId>`) — a Questions database, then that topic's resources, each with a two-column Content/My Notes section generated on demand |
| [learning-dashboard.html](learning-dashboard.html) | Learning Dashboard — a standalone daily-study command center (Home, topic cards, a weekly Gather/Organize/Integrate/Teach workflow, a Daily Study Widget, Research Library, Knowledge Maps, Personal Frameworks, Master Notes with backlinks, Analytics, Settings) — its own crimson/pink theme, genuinely separate from learning.html |
| [dreamboard.html](dreamboard.html) | Dream Board — a drag-and-drop vision board (checklists, calendar, photo/video grid, affirmations, and more) |
| [fitnessstudio.html](fitnessstudio.html) | Fitness Studio — its own new nav folder between Business Dashboard and Entertainment. Genuinely separate from index.html's own embedded Fitness Studio tab. Hero, Today's Workout, a Live Workout Dashboard, Goal Center, Workout Programs, Weekly Schedule, a consistency heatmap, an AI Fitness Coach, Settings (Black/Red/Pink theme), and a music slide-out panel connected live to the Playlists page |
| [writing-dashboard.html](writing-dashboard.html) | Writing Dashboard — its own "Business" nav folder, between Fitness Studio and Entertainment. A full Writing Operating System for multiple fantasy/horror/thriller/romance/sci-fi series at once: a Series Library, a per-series 15-tab Series Dashboard (Worldbuilding Wiki with 56 fixed categories, Character Wiki with a relationship graph, Story Architecture, an interactive trilogy Mind Map, Brain Dump, Tools & Documents, Research, Publishing, Analytics, Timeline, Gallery, Templates), and a per-book 6-tab Writing Workspace (a distraction-free editor with a Quick Lore side panel + an AI Prompt Library side panel, Structure & Beats — real Save the Cat/Hero's Journey/Seven Point/Story Circle/Romance/Three-Act beat sheets plus subplot/foreshadowing/reveal/mystery trackers, Formatting & Export, an honestly-computed Consistency Checker with an optional AI review, and Publishing) — a cinematic black/crimson/charcoal/silver theme built on the glass-theme.css/gallery-card.css kit |
| [youtube-dashboard.html](youtube-dashboard.html) | YouTube Dashboard — a second page in the same "Business" nav folder, right below Writing Dashboard. A full YouTube Business Operating System for unlimited channels at once: a Channels gallery, a per-channel workspace (a cinematic Hero, then Overview/Video Projects — Gallery/Table/Kanban/Timeline/List views/Calendar/Analytics/Assets/Settings), and a per-video Workspace (Overview — with a device-local attached Video File preview/player, Research & Planning, Script — with a fullscreen "Focus Mode" distraction-free writing environment, Production, Publishing & SEO, a one-click-instantiated Checklist, and Analytics & Lessons Learned). One universal Notes database (never duplicated — relationally filtered by scope onto Dashboard Home/every Channel/every Video), Global Templates (13 real Video Templates, a full Checklist Template builder with clone-and-detach instancing, plus Thumbnail/Description/SEO/Title/Branding templates), a global Asset Library, cross-channel Analytics, a Content Calendar, an Archive, and a Ctrl+K Search Everything command palette. Built on the same glass-theme.css/gallery-card.css kit as Writing Dashboard, near-black/gold palette, and the exact same two brand-guideline images → font mapping Writing Dashboard's own Hero already established (normal_text.jpg's bold rounded sans → Poppins body text; banner & title_text.jpg's ornate high-contrast serif → Playfair Display for headings/Hero) — Dashboard Home and every Channel get that same cloned Hero treatment (crest/diamond-flanked metallic title/curling flourish/3-column credit strip). Genuinely separate from businessdash.html's own `kind:'youtube'` Business record and businessos.html's generic `platform:'youtube'` calendar tag — touches neither |
| [aitech.html](aitech.html) | AI & Tech — an AI Models gallery + a linked Prompts database |
| [tasksnotes.html](tasksnotes.html) | Tasks & Notes — Links / Notes / Tasks |
| [mainpillar.html](mainpillar.html) | Main Pillar — gamified daily command center (Whoop biometrics, quest-style habits, tasks, AI journal/briefs, Weekly/Monthly/Year dashboards, Smart Goal Allocation, Favorites archive) |
| [topbar.js](topbar.js) | Shared top bar — auto-injected into pages that `<script src="topbar.js">` |
| [sync.js](sync.js) | Shared Supabase cloud-sync helper |
| [glass-theme.css](glass-theme.css) / [glass-theme.js](glass-theme.js) | Reusable "dark glass" page theme — background glow, glass cards, glare cards, border-beam cards, a cover-photo hero, and drag-reorderable "moveable" sections. Extracted from fitnessstudio.html; drop `<link>`/`<script>` tags into a new page to get the same look/feel (see glass-theme.css's own header comment for how) |
| [gallery-card.css](gallery-card.css) / [gallery-card.js](gallery-card.js) | Reusable gallery card component — cover art, hover-revealed drag handle + edit button, a favorite star toggle, a serif title/creator/subtopic, a clamped description, a 5-star rating row, a length readout, and click-to-open-or-edit. Extracted from ent-stories.html's card (`GalleryCard.build(item, opts)` — see gallery-card.css's own header comment for how) |
| [design-library.html](design-library.html) | Design Library — its own "System" nav folder at the bottom of the sidebar, above Customization. A personal, searchable design knowledge base: one generic Resource model (component/theme/template/animation/palette/background/typography/icon pack/layout) drives ~20 filtered views — Home, per-category galleries, Mobile/Desktop/Dashboard/AI-UI quick filters, Collections, Favorites, Recently Added, Trending, Prompt Library, Saved Code, Personal Uploads — each resource carrying its own AI prompt (with version history), code snippets, a real sandboxed-iframe live preview, and an AI Assistant (Improve/Modernize/Simplify/Expand/Rewrite/Convert Framework/Accessibility & Performance Review/Generate Variants/Generate Matching Theme — real Anthropic calls when a key is set in Customization, an honest local fallback otherwise), plus a Ctrl+K command palette. Built on glass-theme.css/gallery-card.css |
| [customization.html](customization.html) | Customization Studio — the control center for Design Library's and its own appearance: Themes & Appearance (16 presets), Color Studio (13 color roles, a gradient builder, saved palettes, deterministic AI-palette suggestions), Wallpapers, Typography, Icon Library, a Widgets & Components sandbox, Layout Builder, a Navigation Manager genuinely wired dashboard-wide into topbar.js (drag-reorder nav groups, pin pages into a Favorites group), Productivity, AI Settings (saved personas), Integrations (live health of Supabase/Anthropic/PhotoStore/IndexedDB), client-side Automations, Shortcuts, Privacy & Security, real Backup & Restore (full export/import + named snapshots, safe since local-store-idb.js moved storage off the old localStorage quota), Workspace Templates, Experimental Features, and Help |

Each app stores its own state in browser `localStorage`. No accounts, no server.
